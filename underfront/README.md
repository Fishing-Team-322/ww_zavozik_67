# ПУЛЬС — фронтенд

Next.js 16 / React 19 / TypeScript / Tailwind 4. Глобальный шрифт — локально подключённый Inter Variable (`@fontsource-variable/inter`). Основа интерфейса перенесена из `../old_front` согласно `CODEX_TASK.md` и README того набора.

## Что перенесено

- UI-кит в `src/shared/ui`, включая формы, таблицы, диалоги и графики.
- Оболочка кабинета и навигация в `src/widgets/cabinet-shell`.
- Метрики, сигналы и финансовые панели в отдельных срезах `src/widgets`.
- Модели платежей и навигации в `src/entities`, сценарии календаря и авторизации в `src/features`.
- Общие утилиты в `src/shared/lib`; светлая и тёмная тема с зелёным акцентом в `app/globals.css` и `app/puls-accent.css`. Правила слоёв описаны в [`ARCHITECTURE.md`](./ARCHITECTURE.md).

Стили старой платформы (`gov-*`, `tp-*`, карта) не подключены. Авторизация, компании и источники данных используют Go API; календарь и аналитические демо-компоненты пока считают данные локально.

## Маршруты

| URL | Раздел | Текущее состояние |
| --- | --- | --- |
| `/overview` | Обзор | `PulsOverview` с явно помеченными демоданными; `/` перенаправляет сюда |
| `/companies/new` | Новая компания | Создание через API, автозаполнение по ИНН |
| `/transactions` | Операции | Поле поиска и пустое состояние |
| `/forecast` | Прогноз | График и карточка рисков ожидают расчёт |
| `/scenarios` | Сценарии | Демо-сравнение сценариев |
| `/risks` | Кассовые разрывы | Пустое состояние до расчёта |
| `/calendar` | Календарь платежей | Интерактивная демонстрация с локальным пересчётом |
| `/sources` | Источники данных | Реальные источники, загрузки, задания, сопоставление колонок и история импортов |
| `/development/components` | Кнопки и поля | Примеры обновлённых элементов интерфейса |
| `/test` | Платёжный календарь | Интерактивная демонстрация с локальным пересчётом остатков |
| `/login`, `/register`, `/forgot-password`, `/reset-password` | Авторизация | Go API, access token в памяти и refresh-cookie |
| `/privacy` | Документ об обработке данных | Ожидает утверждённый юридический текст до публичного запуска |

Главная страница показывает синтетические данные с пометкой «Демо-данные»; остальные рабочие разделы не показывают вымышленные остатки, вероятности или риски. Дополнительные моковые данные используются на `/test` и `/development/components`. У тонкого общего хедера есть линия снизу, у сайдбара — справа. Аватар пользователя находится справа в хедере и открывает информацию о профиле по наведению или нажатию. Основная область без рамки и тени примыкает к сайдбару и правому краю окна, заполняя высоту от хедера до низа экрана. `CabinetShell` находится в корневом layout и сохраняется при переходах между страницами; вверху каждой страницы он показывает breadcrumbs вместо заголовка. `PageLayout` собирает содержимое страницы и необязательные вкладки. Переключение темы находится в сайдбаре и сохраняется в `localStorage`.

## Подключение Go API

Задайте `BACKEND_ORIGIN` в `underfront/.env.local` как origin запущенного Go API без завершающего `/` и без `/v1`. Next.js проксирует запросы `/v1/*` на этот адрес; клиент не хранит access token в localStorage. Сессия восстанавливается через refresh-cookie и `GET /v1/me`; закрытые страницы ждут проверки сессии. Для писем восстановления на Go API нужен SMTP и корректный `FRONTEND_URL`. Для работы FNS lookup на сервере нужен `DADATA_API_TOKEN`, а для хранения конфигураций источников — `DATA_ENCRYPTION_KEY`. Контракты описаны в `../api/openapi.yaml` и `../docs/BACKEND_API.md`.

При запуске всего проекта через корневой `docker compose up -d --build` отдельный `.env.local` не нужен: Compose передаёт фронтенду внутренний адрес Go API. Локальный `.env.local` используется только при запуске Next.js командой `npm run dev` вне Docker.

Зависимости установлены через npm. Для локального запуска: `npm run dev`.
