# CashGapInspector

Переиспользуемый управляемый компонент принимает `data`, `simulation`, `status`, выбранные действия и callbacks. Он не загружает mock-данные и не выполняет банковские операции. `CashGapInspectorDemo` связывает его с локальным сервисом на `/test`.

- `entities/cash-gap` — контракты событий, действий и API; чистый расчёт дневных остатков, каскада и альтернативы.
- `model/mock-data.tsx` — один фиксированный срез на 1 ноября 2026 года, период 1–30 ноября.
- `api/mock-service.tsx` — асинхронный адаптер `getGap` и `simulate` с отменой запросов и управляемой ошибкой.
- `ui` — сводка, причины, каскадная диаграмма, действия, сравнение и демо-контейнер.

Суммы выражены в целых рублях со знаком. Перенос меняет дату, рассрочка сохраняет сумму исходного события. Комиссии — отдельные расходы. Финансирование включает поступление, возврат и стоимость. События за пределами периода вызывают ошибку, чтобы расчёт не скрывал будущие обязательства. Остатки считаются на конец дня; внутридневная очерёдность не моделируется.

Базовый сценарий даёт остаток −80 000 ₽ 8–9 ноября. Вероятность 64% возвращается как mock-значение. Для альтернативы сервис возвращает `null`: UI показывает «Нет оценки». Эффект каждого действия оценивается отдельно; результат комбинации рассчитывается заново. Отсрочка и рассрочка аренды взаимоисключающие.

На `/test` можно переключать состояния загрузки, отсутствия данных и ошибки; пересчёт появляется при выборе действий. Сценарии сохраняются, загружаются и удаляются только в React-состоянии текущей сессии.

Для подключения `/risks/[gapId]` внешний контейнер получает детали через `GET /companies/{id}/gaps/{gapId}` и передаёт выбранные `actionIds` в `POST /companies/{id}/gaps/{gapId}/simulate`. `CashGapGateway` также описывает `POST /actions/{actionId}/apply`; демо его не реализует и не вызывает. Все визуальные компоненты экспортируются через публичный `index.ts`.
