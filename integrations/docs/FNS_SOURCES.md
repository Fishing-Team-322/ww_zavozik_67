Набор задолженности отражает опубликованный срез и не показывает текущий остаток ЕНС. Данные о погашении после даты среза могут отсутствовать. Сведения ИП из предоставленных выписок не включаются в публичные тестовые файлы проекта.

Статус `IMPORTED_OFFICIAL` следует присваивать только после проверки происхождения конкретного пользовательского файла оператором. Парсер проверяет структуру и контрольные числа идентификаторов, но не доказывает, что загруженный файл действительно выдан ФНС. `signature_status=NOT_VERIFIED` сохраняется всегда, пока нет отдельной проверки УКЭП.
