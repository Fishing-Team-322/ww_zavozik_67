# Wildberries Finance API

На 24.10.2026 ориентир — [официальная документация Finance API](https://dev.wildberries.cn/docs/openapi/documents-and-accounting): `POST /api/finance/v1/sales-reports/detailed` на `finance-api.wildberries.ru`, токен категории Finance в `Authorization`. В запросе период, `rrdId`, `limit`; после страницы передаётся последний `rrdId`, окончание — HTTP 204. Документация указывает лимит один запрос в минуту на кабинет. Старый кандидат из задания `/api/v5/supplier/reportDetailByPeriod` для нового кода не выбран, поскольку в актуальной документации опубликован Finance API.

Адаптер сохраняет продажи, возвраты, логистику и комиссии как строки финансового отчёта с ID отчёта и строки. `forPay`, `acquiringFee`, `deliveryRub` разбираются без `float`; отрицательные суммы допустимы для возвратов/корректировок. Эти строки не создают `actual_operation` и не становятся прогнозным банковским поступлением без отдельного подтверждения выплаты. Тестовый HTTP-сервер проверяет авторизацию, страницы, суммы, возврат и ошибки 401/403/429/5xx. Локального токена WB нет, live-вызов не выполнялся.
