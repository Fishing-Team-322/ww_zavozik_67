# Как подключить данные к ПУЛЬС

## Создать организацию

После регистрации откройте «Создать компанию» или «Организация → + Добавить компанию». Разрешение системного администратора не требуется. Это ваше изолированное рабочее пространство; название и ИНН не выдают доступ к чужому пространству или базе 1С. ИНН необязателен при создании, но нужен для поиска организации и проверки принадлежности банковских документов. Проверяется контрольная цифра.

«Защитный резерв» — порог предупреждений. Он не задаёт начальный банковский баланс. Без подтверждённого остатка интерфейс сообщает, каких данных не хватает. Реальный ноль из выписки отображается как ноль.

## 1С: самый простой путь — файл

1. В разделе «Источники» выберите «Импортировать файлы из 1С».
2. Выгрузите банковскую выписку в формате 1CClientBankExchange, CSV или XLSX и загрузите её в банковский импорт.
3. Для CSV/XLSX проверьте столбцы, для знаковой суммы выберите один столбец в «Сумма» и «Знаковая сумма». Подтвердите импорт и прочитайте отчёт об ошибках строк.

Не нужны OData URL, пароль или ручной ввод счёта. Для файла 1CClientBankExchange укажите ИНН компании в её реквизитах; счёт читается из файла. Файловый импорт сам не обновляется при изменении 1С — нужно загрузить новую выписку. Повтор тех же операций не добавляет дублей.

## 1С по сети

Это несколько действий с участием администратора 1С, а не универсальное подключение по ИНН.

1. Администратор публикует базу с интерфейсом OData, выдаёт URL и отдельную учётную запись чтения, разрешает необходимые справочники и документы. Пример формы адреса: `https://accounting.example.ru/base/odata/standard.odata/` — это пример, не готовый общий endpoint.
2. Оператор ПУЛЬС разрешает точный адрес сервера. Публикация должна быть доступна с машины, где запущен backend. Адрес localhost клиента недоступен серверу без отдельного защищённого соединения.
3. В мастере «Подключить 1С по сети» укажите адрес, ИНН и доступ. Нажмите «Найти организацию и счета».
4. Выберите нужный счёт из найденных, затем «Подключить и синхронизировать». При нескольких счетах можно создать отдельное подключение на каждый. Ручной ввод — дополнительный вариант, если администратор подтвердил номер и публикацию.
5. Проверьте число фактов, счета, даты и результат повторного sync. Счёт без срока остаётся без срока и не включается в прогноз на выдуманный день.

Ошибки адреса/пароля/публикации не означают, что нужно купить API-ключ. OData URL выдаёт администратор именно вашей 1С. Учебная версия иногда ограничивает число одновременных соединений. Промышленная публикация требует отдельной проверки на вашей конфигурации и лицензии.

## Официальная PDF-выписка ФНС

1. Получите PDF ЕГРЮЛ/ЕГРИП на официальном сервисе ФНС.
2. Откройте **«Документы ФНС»**, а не банковский импорт. Поддерживаются PDF с текстовым слоем, XML и ZIP, до 16 МиБ. Изображение/скан без текста не распознаётся.
3. В предпросмотре сверьте ИНН, ОГРН, дату и название. Если записей несколько — выберите нужную.
4. Явно сохраните сведения для контрагента либо своей компании. Для своей компании ИНН обязан совпадать.
5. Сведения появятся в истории и профиле контрагента. Повтор того же документа не создаёт дубль.

Статус подписи `NOT_VERIFIED` означает, что криптографическая проверка не выполнена. Выписка не подтверждает владение организацией, доступ к её 1С или остаток денег. Подтверждение реквизитов не создаёт банковских операций.

## WB и Ozon

Нужен кабинет **продавца**, а не аккаунт покупателя. WB требует токен финансового API, Ozon — Client ID и API Key. Выберите период не более 31 календарного дня и нажмите «Подключить и загрузить отчёт». Начисления, возвраты и комиссии сохраняются отдельно от банковских поступлений. В этой приёмке live-проверка этих API не выполнена, mock-сценарии пройдены.

## Google Sheets

Создайте таблицу с фактическими операциями. Укажите ID из URL, диапазон нужного листа, ключ для доступной таблицы или access token с правом чтения. Предпросмотрите строки, сопоставьте столбцы и подтвердите импорт. Права доступа выдаются в Google; ПУЛЬС не может открыть закрытую таблицу по одному ID. OAuth и продление токена здесь не автоматизированы.

## Повторная проверка и смена ключей

В карточке сохранённого источника доступны «Проверить», «Синхронизировать», «Доступ и параметры», отключение и удаление. В форме обновления заполните только изменившиеся значения; пустые поля сохранят прежние. Секреты не показываются обратно. После изменения источник ожидает проверки. При удалении по умолчанию сохраняются импортированные данные; внимательно прочитайте диалог.

Красная ошибка — повод проверить адрес, права, срок токена или публикацию. Надпись `ДЕМОНСТРАЦИЯ / MOCK` означает синтетические ответы, а не живое соединение. Основной локальный сайт: `http://localhost:3000`; отдельный тестовый sandbox: `http://localhost:3001`.
