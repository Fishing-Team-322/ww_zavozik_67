# Категории из данных: актуальная архитектура

Прямое уточнение пользователя 24.10.2026: модель **сама обнаруживает группы
и формирует весь справочник**. Этот документ заменяет части
`CLASSIFIER_V2_SPEC.md` про 20 исходных категорий, обучение category CE,
обязательный выбор одного известного класса и приёмку по старой accuracy.
Старое supervised-обучение остановлено; его результаты остаются историей.

## Поток

1. Реальные операции → нормализация назначения → pretrained multilingual E5
   → нормированный float32-вектор. Никаких меток категорий, Go-учителя,
   описаний старых классов и синтетики по этим классам.
2. Независимые шаблонные семейства → HDBSCAN отдельно для поступлений и
   списаний. Число категорий определяется данными; шум остаётся без категории.
   Повторы одного шаблона не должны изображать множество независимых примеров.
3. Кластеры → новый версионированный справочник. Название автоматически
   извлекается из характерных слов назначений, с явным статусом
   `auto_extractive`. Это черновое объяснение группы, не заключение бухгалтера.
4. Новые операции → тот же encoder → ближайшие группы с проверкой расстояния
   и неоднозначности. Ответ может быть `unassigned`: пустое назначение,
   неизвестное явление, спорная граница или отсутствие достаточных данных.
   Cosine similarity и margin не называются вероятностью правильного ответа.
5. Накопленные неназначенные операции → обнаружение новых групп → **новая**
   версия справочника. Уже выданные ID не меняются, работающая версия не
   мутирует при отдельном запросе. Автосоздание категорий не требует ручного
   придумывания списка. Ручное переименование/слияние допустимо как исправление.

Платёжный канал и теги остаются отдельными осями, не определяют категории.
Пока их источник — существующие консервативные текстовые правила с явным
обозначением weak evidence. Атрибуты `mandatory` и `flow` нельзя достоверно
вывести из близости векторов: они неизвестны до отдельной проверки.

## Первый воспроизводимый эксперимент

- Pinned `intfloat/multilingual-e5-small`, revision
  `614241f622f53c4eeff9890bdc4f31cfecc418b3`; mean pooling, L2 normalization,
  prefix `query: `, max length128. Изначально без fine-tuning: у нас нет
  независимых пар семантической эквивалентности для честного дообучения.
- Назначение без ИНН/имени/суммы. Направление — отдельное ограничение группы.
  Документы, даты и сумма из текста убираются; каналы не служат названиями
  экономических групп. Это гипотеза представления, а не доказанная оптимальность.
- Сохранены уже замороженные company+template partitions v3. Их распределение
  ранее стратифицировалось слабыми метками; это явно записывается в provenance.
  Новый fit не читает сами метки, synthetic или augmented train.
- Fit только на train. На каждое семейство и направление одна medoid-точка;
  HDBSCAN min_cluster_size3/min_samples2/eom, без заданного числа категорий.
  Новая категория требует минимум3 разных семейств и2 компаний.
- Радиус группы — train-only leave-one-family-out distance quantile95;
  margin0.01. Это эвристический отказ, **не** калиброванная гарантия ошибки5%.
- До просмотра test фиксируются параметры и хэши. Test не участвует в
  кластеризации, именовании, выборе числа групп, порогов или обновлении словаря.

## Проверка

Публикуются число групп/семейств/компаний, доля шума, silhouette (где определён),
устойчивость при удалении семейств, назначение/отказ и margin на новых компаниях
и шаблонах. Эти показатели не доказывают экономическую правильность категорий.
Нужны слепые пары `same/different/uncertain` от независимых разметчиков и
проверка названия/связности/раздробленности каждой группы. Старые weak labels
могут быть лишь внешней диагностикой после заморозки, а не целевой разметкой.

Новый контракт должен возвращать динамический ID и title, версию словаря,
embedding/model version, similarity/margin и причину отказа. Он не может
маскироваться под старые 20 Go-enum или обещать category_probs без калибровки.
Go/backend, forecast и чужой trx остаются вне изменений этой задачи.

Источники реализации:
[E5 model card](https://huggingface.co/intfloat/multilingual-e5-small),
[HDBSCAN API](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.HDBSCAN.html).
