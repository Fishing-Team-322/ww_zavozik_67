# Интеграции ПУЛЬС — проверка V2, 24.10.2026

`LIVE` означает запрос к настоящему источнику, `MOCK` — воспроизводимый искусственный ответ. Наличие формы само по себе не подтверждает доступ к сервису. Основной сайт работает с реальными поставщиками; mock включается только в отдельном локальном sandbox.

Во всех маршрутах ниже `C` — UUID рабочего пространства с проверкой membership, `S` — UUID его источника. Секреты источников сохраняются AES-GCM в `sources.config_secret`, не возвращаются в API и экспорте. `PATCH /v1/sources/S` с `config` объединяет новые значения с сохранёнными, проверяет полученную конфигурацию и сбрасывает статус в `pending`. Для удаления секрета нужно явно передать пустое значение, где это разрешено адаптером.

## Общие ограничения при публичном запуске

- SMTP, OAuth, УКЭП ФНС, кабинеты продавцов, реальная таблица, реальная промышленная 1С и удалённый HTTPS требуют отдельных доступов/приёмки. Они не объявлены проверенными.
- Сетевые подключения поддерживают сохранение, проверку, ручной sync, обновление доступа, отключение/включение, удаление с сохранением данных. Общее расписание sync пользовательских источников в этой версии не заявляется; расписание ФНС настраивается в Hub отдельно.
- Автоматического банковского API и локального агента 1С здесь нет. Проверенные пути — файлы и опубликованный OData.
- Известный счёт из справочника 1С подтверждает связь в этой базе, но не юридическое владение. Совпадение ИНН с PDF не выдаёт права на чужое пространство.
