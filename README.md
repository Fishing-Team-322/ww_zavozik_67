# ww_zavozik_67 — прогноз денежных потоков для малого бизнеса

Кейс банка «Центр-инвест», хакатон «Осень 2026». Сервис прогнозирует остаток
на счёте на 30+ дней, находит кассовые разрывы (дата, сумма, вероятность)
и подсказывает, что сделать.

## Быстрый старт

Датасет кейса распаковать в `cashflow_dataset_participants/` (в git не коммитится).

```bash
make up                # postgres + ml + api + worker в Docker, API на :8080
curl localhost:8080/healthz
make test              # go test + pytest
make backtest          # бэктест на датасете → ml/data/backtest.csv
```

Перед первым `make up` скопировать `.env.example` в `.env`, задать случайный
`JWT_SECRET` (минимум 32 байта) и пароль Postgres. Compose применяет миграции
отдельным сервисом `migrate` до старта API. Аккаунты, компании, сессии и облачное
состояние описаны в [ACCOUNTS_API.md](docs/ACCOUNTS_API.md).

Без Docker:

```bash
make ml-venv           # один раз
make ml-serve          # ML-сервис на :50051
make backtest ML=localhost:50051
cd backend && go run ./cmd/api
```

Для загрузок, синхронизации и выгрузок дополнительно запустить `go run ./cmd/worker`
из `backend/` с теми же `DATABASE_URL` и `DATA_ENCRYPTION_KEY`, что у API.
Финансовые методы используют постоянные данные компании; все маршруты документа
экранов включены в OpenAPI. Настройка интеграций — в [инструкции API](docs/BACKEND_API.md).

Фронтенд работает с API; запуск — в [underfront/README.md](underfront/README.md).
Для отдельной проверки контракта также доступен mock:

```bash
npx @stoplight/prism-cli mock api/openapi.yaml
```

## Как добавлять

- **Эндпоинт:** правим `api/openapi.yaml` → `make gen-api`. Строгие адаптеры
  финансовых методов генерируются в `product.gen.go`, бизнес-обработчик добавляется
  в `backend/internal/product`. Аккаунты реализованы в `httpapi/platform.go`.
  `Server` больше не наследует заглушки 501; контракт и обработчик обновлять вместе.
- **Прогнозная модель:** класс в `ml/zavozik_ml/forecasters/` с `@register` —
  сразу доступна через gRPC и в `make backtest ML=... ` (`-model <name>`).
- **Источник данных:** тип в `backend/internal/sources/<name>/` +
  `sources.Parsers.Register` или `sources.Pullers.Register` в `init()`.
- **Сценарий, действие, канал уведомлений, LLM:** то же — интерфейс и реестр
  в соответствующем пакете `backend/internal/`.
- **Контракт ML:** правим `proto/` → `make gen-proto`.

Генерация требует `buf`, `protoc-gen-go`, `protoc-gen-go-grpc`:

```bash
go install github.com/bufbuild/buf/cmd/buf@v1.47.2
go install google.golang.org/protobuf/cmd/protoc-gen-go@v1.36.5
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@v1.5.1
```

## Качество прогноза

Проверка как на чужом наборе данных: кросс-валидация по компаниям на 5 групп,
каждая из 150 компаний оценена моделью, которая её не видела; модель
переобучается раз в месяц и знает только прошлое относительно даты прогноза.
814 прогонов, горизонт 30 дней, данные после строгой подготовки (дубли
подтверждены сверкой остатка, пропуски выписки учтены).

| Модель | WAPE 7 / 14 / 30 дней | Ошибка к naive | Лучше naive | Покрытие p10–p90 | Разрывы: Brier / AUC / полнота |
|---|---|---|---|---|---|
| **Ансамбль LightGBM + naive** (`auto`) | **21,9 / 32,7 / 48,4%** | **0,85** | **69%** | 85% | **0,105** / **0,90** / 94% |
| LightGBM глобальная | 22,5 / 32,6 / 45,9% | 0,83 | 63% | 81% | 0,106 / 0,89 / 92% |
| Seasonal naive (бейзлайн) | 23,3 / 36,5 / 58,8% | 1,00 | — | 77% | 0,117 / 0,90 / 94% |

О кассовом разрыве предупреждаем в среднем за ~11 дней. Что дало прирост:
производственный календарь РФ (открытые данные), признаки «год назад»,
регуляризация бустинга под новые компании, смесь с naive. Больше половины
движения остатка за месяц — переводы владельца (займы учредителя, свои средства
из другого банка); по потокам бизнеса их не предсказать, поэтому разрыв
считаем по остатку без докачки владельцем.

Классификатор операций: закрытый список из 20 категорий, классифицирует по
смыслу операции (цифровой рубль — обычные рубли), 97,9% на 280 новых
формулировках, которых нет в датасете.

## Безопасность

- Суммы, ИНН, названия контрагентов и назначения — отдельные типы в
  `backend/internal/domain`, в логах всегда `[REDACTED]` (есть тест).
- ML-сервис наружу не публикуется, пишет в лог только размеры запроса.
- LLM — российский провайдер или обезличивание (152-ФЗ).
