# Обучение

Сюда — претрейн энкодера последовательностей на MBD
(huggingface.co/datasets/ai-lab/MBD) и дообучение на прогноз дневных
притоков/оттоков с квантилями. Зависимости: `pip install -e ".[train,dev]"`.

Готовая модель регистрируется в `zavozik_ml/forecasters/` через `@register`
и грузит веса из `ml/artifacts/` (в git не коммитим).

Датасет кейса в обучение не идёт — это отложенная выборка для бэктеста.
