# Классификатор категорий: linear-v1

Версия `classifier-v1-dac291770bf320c9`, обучен 2026-10-24. Первая рабочая
модель категоризации операций, снимок того, что сейчас обслуживает gRPC-сервер
(`ml/artifacts/classifier`).

## Что делает

Одна операция → одна категория из закрытого списка в 20 категорий + уверенность.
Новых категорий не создаёт. Ниже порога уверенности 0.3 отвечает `other`.

Категории: revenue_acquiring, revenue_sbp, revenue_cash, revenue_b2b,
revenue_marketplace, supplier, salary, tax, rent, utilities, loan_payment,
leasing, bank_fee, marketing, services, own_transfer, owner_loan, refund,
enforcement, other.

## Устройство

- **Вход:** назначение платежа, название контрагента, тип контрагента по длине
  ИНН (организация / ИП или физлицо / пусто), направление, сумма. ИНН в признаки
  не идёт.
- **Признаки:** хэшированные (2^18) слова, биграммы и символьные 3–5-граммы
  назначения и названия, в паре с направлением. Упоминание цифрового рубля
  вырезается: это способ платежа, а не смысл операции.
- **Модель:** мультиномиальная логистическая регрессия, температурная
  калибровка (T = 0.643). Инференс — только numpy.
- **Метки:** правила Go + ручная доразметка шаблонов, где правила давали
  `other`; аугментация опечатками, сокращениями, новыми каналами платежа.

## Качество

| Проверка | Размер | Accuracy |
|---|---:|---:|
| Отложенные компании | 50 148 операций | 99.87% |
| Новые формулировки (нет в датасете) | 280 примеров | 97.86% |
| Без названия контрагента | 254 примера | 95.28% |

Метки на отложенных компаниях — от правил, а не от людей; независимой
человеческой разметки пока нет. Подробно — `ml/reports/classifier.md`.

## Как загрузить

```python
from pathlib import Path
from zavozik_ml.classify.model import Classifier
from zavozik_ml.classify.text import Op

clf = Classifier.load(Path("ml/models/classifiers/linear-v1-dac291770bf320c9"))
clf.predict([Op(direction="out", purpose="Оплата цифровыми рублями поставщику за товар",
                counterparty_name="ООО «Агроснаб»", counterparty_inn="0071234567")])
```

Код модели — `ml/zavozik_ml/classify/`, обучение —
`python -m zavozik_ml.classify.train`.
