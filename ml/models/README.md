# Готовые модели

Здесь лежат выпущенные модели: каждая — в своей папке, с весами и описанием.
Папка модели не меняется после выпуска; новая версия — новая папка.

```
ml/models/
  classifiers/              категоризация операций
    linear-v1-<hash>/       README.md + веса
  forecasters/              прогноз денежного потока (появится)
```

## Правила

- **Имя папки:** `<архитектура>-v<номер>-<короткий хэш версии>`, например
  `linear-v1-dac291770bf320c9`.
- **В каждой папке** `README.md`: что модель делает, вход и выход, как обучена,
  на чём проверена и с какими цифрами, хэши файлов, как загрузить.
- **Метрики** — только из воспроизводимого прогона; источник отчёта указан.
- **Сервер** пока грузит модели из `ml/artifacts/` (`ML_ARTIFACTS`). Переход на
  `ml/models/` — отдельным изменением вместе с выбором активной версии.
