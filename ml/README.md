# ML: прогноз денежного потока

Python-сервис без состояния (gRPC, `proto/forecast/v1`) + обучение и оценка.
Go присылает дневную историю компании, сервис возвращает пути прогноза
притоков/оттоков на горизонт — из них Go строит коридор остатка,
вероятность разрыва и «можно потратить».

## Цикл работы

```bash
make ml-venv                 # один раз
make ml-backtest             # export из Go → сравнение моделей → ml/data/backtest_py.*
cd ml && PYTHONPATH=gen .venv/bin/python -m zavozik_ml.eval.report   # ml/reports/quality.md + PNG
make ml-train                # обучить глобальные модели на всех данных → ml/artifacts
make ml-serve                # gRPC на :50051, подхватывает ml/artifacts
```

`make ml-backtest MODELS=seasonal_naive,gbm_global` — только выбранные модели.
Главная оценка — как на чужих данных: `python -m zavozik_ml.eval.backtest --cv 5`
(каждая компания оценена как новая).

Производственный календарь — `zavozik_ml/calendar_data/` (xmlcalendar.ru);
на новый год добавить файл `ru_<год>.json`. Без файла — пятидневка.

## Модели (`zavozik_ml/forecasters/`)

| Модель | Что | Обучение |
|---|---|---|
| `seasonal_naive` | бутстрап по дню недели за 8 недель — бейзлайн | нет |
| `ets` | Holt-Winters с недельной сезонностью, отдельно на компанию | на лету |
| `gbm_global` | LightGBM по всем компаниям: производственный календарь РФ, «то же число месяц назад», «год назад», регулярные платежи по категориям; сильная регуляризация под новые компании; разброс — блоки остатков модели на прошлых точках старта, ширина откалибрована под покрытие 80% | `make ml-train` |
| `ensemble` | смесь путей `gbm_global` и `seasonal_naive` 50/50 — `auto` | через `gbm_global` |

`auto` = лучшая готовая модель (`AUTO_PREFERENCE` в `forecasters/base.py`).
Новая модель: класс с `@register` + импорт в `forecasters/models.py`.

## Данные

`ml/data/flows.csv` — выгрузка `backend/cmd/export`: дневные потоки бизнеса
(без переводов владельца), пропуски выписки, остаток, суммы по 20 категориям
(категоризация — правила Go, единые с продом). В git не коммитится.

## Бэктест (`zavozik_ml/eval/backtest.py`)

6 точек старта на компанию с шагом 30 дней, горизонт 30, без пропусков в окне —
как в Go-бэктесте (naive совпадает с ним до десятых). Глобальные модели
переобучаются раз в месяц только на прошлом и не видят 20% компаний.
Метрики и определения — в docstring модуля и в `ml/reports/quality.md`.
